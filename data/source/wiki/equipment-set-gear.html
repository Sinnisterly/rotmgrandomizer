Equipment Set Gear

Similarly to set tier items, these special equipment pieces can be often used in combination to provide different relative bonuses and/or effects with more items when worn in conjunction. Most of the items are event exclusive and periodically return during their respective event times.

Below is a list of currently available gear set items in the game.

  • Agents of Oryx Gear
  • Alien Gear
  • Neo Alien Gear
  • Antinomy Gear
  • Aspirant's Gear
  • Mistake Gear
  • Construction Gear
  • Oryxmas Gear
  • Syndicate Gear
  • Ancient's Curse Gear
  • Blooming Oasis Gear
  • Mardi Gras Gear
