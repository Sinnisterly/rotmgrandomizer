Notes
The Phylactery Mystic Set was the sixth ST set, becoming available from Release 27.7.5 (Dec 2015).

Wearing the full set transforms the mystic player into a 16x16 Phylactery Bearer sprite and changes the weapon’s shot to appear larger when attacking.

This set was reskinned in Halloween 2019 and dropped in place of this set for the duration of the event; see Totalia Mystic Set.

History
The set was first made available through The Alchemist in Release 27.7.5 (Dec 2015), but was later added as drops from various bosses in the Lair of Draconis, and later from Phylactery Bearers in Patch 27.7.X5 (Sep 2016). In Patch 27.7.XMAS (Dec 2016), the items were removed as drops from the Lair of Draconis, which now drops the Dragon Tamer Set.

Before Exalt Version 5.12.0.0 (June 2025), this set’s bonuses were as follows:

2nd piece bonus: +2 SPD, +1 DEX, +5 WIS
3rd piece bonus: +40 MP, +10 DEF
4th piece bonus: +35 HP, +5 ATT

Before Exalt Version 6.13.0.0 (Aug 2026), this set’s bonuses were as follows:

2nd piece bonus: +20 HP, +15 MP, +6 SPD, +7 WIS
3rd piece bonus: +20 HP, +15 MP, +6 DEF, +8 VIT
4th piece bonus: +20 HP, +15 MP, +7 ATT, +6 DEF

Trivia
It should be noted that this is one of two legacy set tier sets in the game that is still tradable and still has the stat bonus from equipping them. The second is the Priest of Geb set.
