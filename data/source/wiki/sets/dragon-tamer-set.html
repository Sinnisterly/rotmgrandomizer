Dragon Tamer Set

Set Generation
Class Warrior
Themed on Unknown
Drops From Pyyr the Crimson Dragon ( / / / )
Mighty Quest Chest ( / / / )
Obtained Through Mystery Boxes
2nd Piece Bonus +5 ATT, +10 SPD
3rd Piece Bonus +30 HP, +30 MP, +5 DEF, +5 DEX
4th Piece Bonus +55 HP, +50 MP, +5 ATT, +5 SPD, +5 DEX
Subtotal of Bonuses +85 HP, +80 MP, +10 ATT, +5 DEF, +15 SPD, +10 DEX
Overall Stat Bonus +200 HP, +80 MP, +10 ATT, +32 DEF, +33 SPD, +10 DEX
Final Stats at 8/8 1,000 HP, 380 MP, 85 ATT, 57 DEF, 83 SPD, 60 DEX, 75 VIT, 50 WIS
Total XP Bonus 22%
Soulbound
Released Patch 27.7.XMAS (Dec 2016)

Notes
The Dragon Tamer Set is the seventh special themed ST set, becoming available from Patch 27.7.XMAS (Dec 2016).

Wearing the full set transforms a Warrior into a 16x16 Dragon Tamer sprite and changes the weapon’s shot to appear larger when attacking.

History
This was the first ST set that was not based on any enemies in the game. It was also the first ST set to be made soulbound to guard against duping attempts, and all other sets that came after it were also Soulbound.

The stat bonus for 3 pieces was originally +5 DEX and +10 DEF; this was changed in Patch X.31.8.0 (July 2019).

The set had different item sprites prior to Exalt Version 2.3.0.0 (Mar 2022).

Before Exalt Version 6.2.0.0 (Oct 2025), this set had bonuses:
3 Piece Bonus: +5 DEX, +80 MP
4 Piece Bonus: +75 HP
