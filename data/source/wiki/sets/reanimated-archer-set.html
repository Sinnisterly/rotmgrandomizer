Reanimated Archer Set

Set Generation
Class Archer
Reskin of Phantom Archer Set
Themed on A Skeleton
Obtained Through Witch’s Skull
Halloween Mystery ST Chest
2nd Piece Bonus +20 HP, +20 MP, +3 ATT, +3 SPD
3rd Piece Bonus +30 HP, +30 MP, +3 DEF, +6 SPD
4th Piece Bonus +50 HP, +50 MP, +6 ATT, +6 DEF
Subtotal of Bonuses + 100 HP, +100 MP, + 9 ATT, +9 DEF, +9 SPD
Overall Stat Bonus TBA
Final Stats at 8/8 TBA
Total XP Bonus 16%
Soulbound
Released Patch X.32.0.5 (Oct 2019)

Notes
This is a reskinned version of the Phantom Archer Set, released in Halloween 2019.

History
Before Exalt Version 1.0.3.0 (Sep 2020), the 4th Piece Bonus granted +105 HP only.

Before Exalt Version 6.4.0.0 (Dec 2025), this set’s bonuses were as follows:

2nd piece bonus: +5 DEX, +5 VIT
3rd piece bonus: +95 MP, +11 DEF
4th piece bonus: +105 HP, +6 ATT

Trivia
The descriptions for each of the items in this set are references to the song Spooky Scary Skeletons by Andrew Gold.
