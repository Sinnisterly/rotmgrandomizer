Notes
This Archer set is soulbound. The low stat bonuses and poor utility of the items mean this set is, for all intents and purposes, a vanity set.

The set is a humorous nod towards possibly the most infamous RotMG package ever sold during the Kabam era, the Golden Archer Pack:

The package, which comprised only mid-tier items and a very weak ring, but also an Incantation (items all freely available to obtain via trading), reflected quite poorly on Kabam, as either they did not understand the value of items in their own game, or it was an unsubtle attempt to monetise Incantations. In any case, most of the playerbase regarded the package as a joke, and it became infamous in the game’s history.

The set reflects this with its praising descriptions and horrendous stats.

History
The Golden Archer Set was the fifteenth special themed set to be released, in Patch X.31.5.0 (Apr 2019), for April Fool’s Day.

Before Exalt Version 6.8.0.0 (Mar 2026), this set was soulbound.
