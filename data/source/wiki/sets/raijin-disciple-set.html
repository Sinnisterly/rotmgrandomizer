Notes
The Raijin Disciple Set was the sixteenth ST set to be released.

All of the set pieces drop from various bosses and enemies of the Secluded Thicket dungeon.

The set is all about offense. With a massive +12 to ATT, DEX, and SPD, coupled with the immense damage output on the Reikoku, a Raijin Disciple can lay waste to nearly anything it can reach. However, although the set provides a decent HP boost, it suffers from a crippling lack of DEF, which may inhibit the player since the Reikoku has a very short range. However, the Shuriken’s Armored effect can subvert this somewhat, although it can only be activated for precious few seconds at a time.

Wearing the full set transforms the player into a 16x16 Raijin Disciple sprite and changes the weapon’s shot. The set confers additional stat bonuses when all the items are worn together.

History
Before Exalt Version 2.0.2.0 (Aug 2021), Hirejou Tenne used to drop from Tezcacoatl the Great Basilisk, the first boss of Secluded Thicket. Because Tenne is such a sought after DPS item, some groups of players would buy keys to chain only the first boss in an attempt to get one quickly. The change was not officially announced until 6th October.

In Exalt Version 5.6.0.0 (Jan 2025), the set bonus got changed. Before, the 2 Piece Bonus gave +4 DEF, +7 SPD, the 3 Piece Bonus gave +4 ATT, +4 DEX and the 4 Piece Bonus gave +75 HP.

Trivia
All of the set’s item descriptions are written in the form of Haiku (5-7-5 Japanese poetry).

Raijin (雷神) is a Japanese and Shinto mythological god that commands lightning and thunder, which is fitting for items that drop from the Secluded Thicket, with its last boss being referred to as a lightning god.
