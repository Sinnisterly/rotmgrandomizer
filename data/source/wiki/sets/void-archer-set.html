Void Archer Set

Class Archer
Themed on The Void
Drops From Void Entity ( / / / )
Voided Epic Quest Chest ( / / / )
Overall Stat Bonus +110 HP, +110 MP, +36 DEF, -1 SPD
Final Stats at 8/8 810 HP, 362 MP, 75 ATT, 61 DEF, 49 SPD, 50 DEX, 40 VIT, 50 WIS
Total XP Bonus 29%
Soulbound
Released Patch X.16.0 (Aug 2017)

Notes
The Void Archer Set is an extremely rare set to assemble, being made of four white bag items from arguably one of the toughest bosses in the game.

The bow and quiver are some of the strongest items in their slot, though the bow faces competition with the Warmonger and T14 Bow of Deep Enchantment. The armor and ring are niche, but can see use in certain types of character.

History
Before Patch X.32.7.0 (Feb 2020), this set had a stat bonus of +110 HP, +110 MP, +23 DEF, +2 SPD.

Before Exalt Version 1.5.0.0 (May 2021), this set had a stat bonus of +110 HP, +110 MP, +26 DEF.

Before Exalt Version 3.3.5.0 (Mar 2023), this set had a stat bonus of +110 HP, +110 MP, +32 DEF, +1 SPD.
