Overall Stat Bonus +30 HP, +20 MP, +3 ATT, +14 DEF, +3 SPD, +3 DEX, +10 WIS
Total XP Bonus 16%
Released Patch X.31.9.0 (Aug 2019)

Notes
Wearing the full set transforms the wizard player into a 16x16 Twilight Archmage sprite and changes the weapon’s shot to appear larger when attacking.

History
This set was previously named Twilight Archmage Set and was the fifth special themed set to be released. The items were first made available via The Alchemist, and were later added as drops from various enemies in The Shatters dungeon.

In Patch X.31.9.0 (Aug 2019) the set was renamed to Legacy Twilight Archmage Set and all the pieces were renamed as Legacy. A new version of the Twilight Archmage Set was released with soulbound items, and the four pieces of the Legacy set were removed as drops from enemies. The additional bonus stats for wearing multiple parts, or the full set, were also removed from the Legacy set at this time.
