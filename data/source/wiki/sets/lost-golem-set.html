Notes
The Lost Golem Set is the ninth ST set to be released. It drops from various enemies in the Lost Halls.

As the set drops from a lategame dungeon, it is expected for all these items to have some sort of viability. The Brain’s unique, stationary decoy can be very useful, and the lack of teleport can be ignored in order to activate the whole set. The dagger’s range and this set’s VIT also make this set amazing if you don’t have a great pet (though whenever you should be doing the Halls without one is another question). The armor is fairly strong on its own, while the ring is really only good to activate the entire ST bonus.

History
Before LH 2.0, this set gave:

Set Additional Bonus: +40 HP, +3 DEF, +15 VIT, +6 ATT, +5 DEX
Overall Stat Bonus: Wearing the entire Lost Golem set will grant in total:
+80 HP, +8 ATT, +22 DEF, +5 SPD, +3 DEX, +27 VIT

Keep in mind that these bonuses were before the X.31.4 update, so one would have needed to wear the entire set in order to receive any additional bonuses.

Before Exalt Version 6.2.0.0 (Oct 2025), this set had bonuses:
3 Piece Bonus: +10 ATT, +5 DEX
4 Piece Bonus: +40 HP
