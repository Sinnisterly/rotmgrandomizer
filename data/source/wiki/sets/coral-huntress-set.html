Coral Huntress Set

Class Huntress
Themed on Ocean Trench
Drops From Thessal the Mermaid Goddess ( / / /)
Coral Gift ( / / /)
Mighty Quest Chest ( / / /)
Overall Stat Bonus +75 MP, +16 DEF, +12 SPD, +8 DEX, +5 WIS
Final Stats at 8/8 750 HP, 380 MP, 65 ATT, 41 DEF, 62 SPD, 68 DEX, 40 VIT, 65 WIS
Total XP Bonus 22%
Soulbound
Released Build 122 (Feb 2012)

Notes
The Coral Huntress Set and the Crystal Necromancer Set were the first themed sets to be released, in Build 122 (Feb 2012).

This set is quite decent in its entirety (roughly equal to WC tops), if a little weak defensively. The weapon, ability, and armor are all good choices. Even the ring helps with MP saving, though most players will prefer a more defensive ring option.

Time hasn’t done this set too well; it was quite prestigious when it first came out.
