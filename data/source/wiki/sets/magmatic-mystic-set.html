Notes
The Magmatic Mystic Set is the 22nd ST set to be released, alongside the Crystal Kunoichi Set and Acidified Assassin Set. It is the third ST set for the Mystic after the Phylactery Mystic Set and the Totalia Mystic Set.

History
Before Exalt Version 6.13.0.0 (Aug 2026), this set’s bonuses were as follows:

2nd piece bonus: +30 HP, +3 ATT, +3 SPD, +5 VIT
3rd piece bonus: +25 HP, +60 MP, +5 ATT, +10 VIT
4th piece bonus: +50 HP, +20 ATT, +5 SPD, +15 VIT
